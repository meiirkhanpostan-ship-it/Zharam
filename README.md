# Жарам 🥫

Тауарлардың жарамдылық мерзімін есте сақтап, мерзімі жақындағанда ескертетін қарапайым веб-қосымша.

## Мүмкіндіктері
- Тауар қосу: атауы, жарамдылық мерзімі, саны, санаты, ескертпе
- Әр тауар үшін «неше күн бұрын ескерту» керегін өзіңіз белгілейсіз
- Түспен белгілеу: 🔴 мерзімі өткен, 🟠 жақында бітеді / бүгін бітеді, 🟢 жарамды
- Мерзімі бойынша автоматты сұрыптау, іздеу және сүзгі
- Браузер хабарландырулары (әр тауар туралы күніне бір рет)
- Өзгерту, жою, JSON сақтық көшірме және қалпына келтіру
- Интернетсіз жұмыс істейді, телефонға қосымша ретінде орнатуға болады (PWA)

## Іске қосу
Компьютерде:
```bash
python3 -m http.server 8000
```
содан кейін браузерде `http://localhost:8000` ашыңыз.

Телефонда пайдалану үшін оны GitHub Pages-ке жариялап (Settings → Pages → Branch),
браузерден ашып, «Басты экранға қосу» батырмасын басыңыз.

## Ескерту туралы
Деректер тек сол құрылғының браузерінде (localStorage) сақталады.
Ескертулер қосымша ашылғанда және ашық тұрғанда тексеріледі — сервері жоқ
веб-қосымша жабық тұрғанда хабарландыру жібере алмайды.
